# Security

AniketosHEN is unofficial PS5 homebrew. There is no warranty.

If AniketosHEN crashes, hangs, or a setting is wrong, open a bug report in
this repository's issue tracker (the "Bug report" template). Include firmware,
version, how it was loaded, and logs from `/data/AniketosHEN/`.

Please do not report AniketosHEN problems to the OnionHEN project unless you
have reproduced them with an OnionHEN build: its maintainers did not ship
this distribution.

To keep a report private, use this repository's Security tab.
